# newsletter-analysis

AI-powered newsletter/article analysis dashboard (Streamlit + Google Gemini).

The app lives in [`streamlit_app/`](streamlit_app/README.md); see that README for features and API-key setup.

## Quick start

```bash
cd streamlit_app
pip install -r requirements.txt
streamlit run app.py
```

## Tests

```bash
cd streamlit_app
pip install -r requirements-dev.txt
pytest
```
